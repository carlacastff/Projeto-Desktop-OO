# Projeto-Desktop-OO
Projeto de orientação a objetos.

## Sobre o Projeto
Este projeto chamado de 'Space Invaders: Star Wars', é um jogo 2D desenvolvido em Python (Pygame), inspirado em Space Invaders e Star Wars: Uma Nova Esperança. Nele, você controla Wedge Antilles, piloto da Aliança Rebelde, em uma missão para destruir os Tie-Fighters e abrir caminho para que Luke Skywalker destrua a Estrela da Morte. Cada fase do jogo representa uma parte da batalha de Yavin 4.

O gameplay é realizado utilizando as setas (← →) para movimentar, a barra espaço do teclado para atirar e pular cutscenes, enter para confirmar a opção no menu e ESC para fechar a janela.

Este projeto é apenas para fins educacionais.

## Funcionalidades
  - **Tela inicial**, menu e sistema de navegação;  
  - **Cutscenes animadas** com som de digitação e textos narrativos;  
  - **Sistema de fases progressivas** com dificuldade crescente;  
  - **Explosões animadas** e efeitos sonoros personalizados;  
  - **Controle do jogador** com movimento e tiros duplos;  
  - **Inimigos simples** com disparos aleatórios.

## Como rodar o projeto
  1. Clone o repositório:  git clone https://github.com/carlacastff/Projeto-Desktop-OO.git
  2. Entre na pasta do projeto:  cd Projeto-Desktop-OO
  3. Instale as dependências:  pip install pygame
  4. Execute o jogo:  python main.py
